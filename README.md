# 🛍️ Shop ERP - Advanced Point of Sale & Business Management System

An enterprise-grade, full-stack **Shop ERP and POS (Point of Sale)** application designed to streamline daily retail operations, inventory management, multi-branch control, and financial tracking. Built with modern web technologies and advanced AI integration.

---

## 🚀 Key Features & Modules

* **📊 Comprehensive Dashboard:** Real-time financial overview including Total Income, Expenses, Net Profit, Dues, EMI Receivables, cash/bank balances, and visual analytics (revenue trends and payment method charts).
* **🛒 POS & Sales Management:** Fast checkout system, automated receipt generation, and smooth order handling.
* **📦 Product & Inventory Control:** Real-time stock tracking, categorization, low-stock alerts, and product return management.
* **💳 Financial & Bank Accounts:** Tracks multiple financial streams including Cash, Bank accounts, bKash, Nagad, Rocket, and card collections.
* **🛠️ Service & Repair Management:** Dedicated modules to manage customer service requests, parts costs, technician expenses, and service revenues.
* **👥 Multi-Branch & Employee Control:** Manage multiple branch locations from a centralized dashboard along with employee tracking and role management.
* **📈 Advanced Reporting & CRM:** Daily, monthly, and yearly reports, customer tracking, subscription management, and activity logs.
* **🤖 AI Business Summary & Suggestions:** Integrated AI assistant capability to generate smart monthly performance insights and sales booster suggestions.

## 🛠️ Technology Stack

### **Frontend:**
* **React.js** (Component-based UI)

### **Backend & Database:**
* **Node.js** (Server-side runtime)
* **Express.js** (Backend framework)
* **MongoDB** (NoSQL database for flexible and scalable data handling)

### **Deployment & Development Tools:**
* **VPS (Virtual Private Server)** (Production hosting & environment)
* **Custom Domain** (Branded web access)
* **Claude Code** (AI-assisted development, debugging, and code optimization)

## ⚙️ Getting Started (Local Development)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/alif616/shop-erp.git
   ```
2. **Install Server Dependencies:**
   ```bash
   cd backend
   npm install
   ```
3. **Install Client Dependencies:**
   ```bash
   cd frontend
   npm install
   ```
4. **Configure Environment Variables:**
   * Create a `.env` file in both client and server directories with your MongoDB URI, Port, and secret keys.
5. **Run the Application:**
   * Start backend server and React client app.
